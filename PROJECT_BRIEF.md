# Project Brief

## Summary

This project is a personal financial spending analysis dashboard. It allows an individual user to upload CSV files downloaded from their bank, store those files, parse the transaction rows, view all transactions in a unified table, and analyze spending habits through an interactive dashboard.

## Target User

An individual who wants to better understand their personal spending patterns without manually managing spreadsheets.

## Problem

Bank transaction exports are usually CSV files that are hard to analyze over time. Users need a simple way to combine multiple exports, clean them into a consistent format, and visualize their spending.

## Solution

A responsive web application where users can:
- Create a secure account.
- Upload one or more transaction CSV files.
- View uploaded files.
- Delete files.
- View cleaned transaction records.
- Analyze spending by category, merchant, transaction type, week, month, and custom date range.

## MVP Scope

The MVP should support:
- User authentication.
- CSV upload.
- File metadata storage.
- Basic CSV parsing.
- Transaction normalization.
- Uploaded files page.
- Transactions table page.
- Dashboard page.
- Responsive desktop and mobile design.

## Future Scope

Future versions may include:
- Smarter transaction categorization.
- Duplicate detection.
- Budget tracking.
- Recurring transaction detection.
- Net income vs spending analysis.
- Export cleaned data.
- Bank integration.
- Multi-account support.
